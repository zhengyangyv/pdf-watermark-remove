# PDF 水印去除工具（Python + OpenCV）

基于 Python 的 PDF 水印去除工具，使用 OpenCV 图像处理实现水印自动识别、文字/图片保护、网格化局部修复，并提供差分法效果数据分析与图形界面。

## 功能特性

- **水印自动识别**：基于 HSV 颜色空间构建亮灰水印掩码（亮度 V∈[170,254]、饱和度 S≤60）
- **文字/图片保护**：深色文字（灰度<140）邻域膨胀扣除、真实图片包围盒挖除，正文零损伤
- **网格化局部修复**：页面 5×5 网格定位水印窗格，仅处理有水印区域，无水印区域无处理痕迹
- **差分法数据分析**：逐页统计水印去除率与文字保留率，matplotlib 输出可视化图表
- **图形界面**：tkinter 窗口，文件选择、参数设置、实时进度与日志、一键分析

## 环境依赖

- Python 3.11+
- pymupdf（PyMuPDF）1.28+
- opencv-python 5.0+
- numpy 2.4+
- Pillow 12+
- matplotlib（数据分析与图表）

安装：

```bash
pip install pymupdf opencv-python numpy Pillow matplotlib
```

## 快速开始

### 图形界面版（推荐）

```bash
python pdf_watermark_gui.py
```

弹出窗口后：选择输入 PDF → 设置输出路径与 DPI → 点击"开始去水印" → 完成后可点击"运行数据分析"查看效果图表。

### 命令行版

```bash
# 单文件（Windows 下无参数运行会自动弹出文件选择窗口）
python pdf_watermark_remove.py 输入.pdf [输出.pdf]
```

### 数据分析模块（单独运行）

```bash
python analyze_results.py 原.pdf 处理后.pdf [-o 图.png]
python analyze_results.py --folder 原文件夹 处理文件夹
```

## 实现原理

1. 将 PDF 页面按 300 DPI 渲染为位图（numpy 数组）
2. HSV 颜色空间阈值检测生成水印二值掩码
3. 深色文字邻域膨胀 + 图片包围盒挖除，实现正文保护
4. 5×5 网格划分，定位"浅灰占比高且处理后降幅明显"的水印窗格
5. 仅对水印区域填背景色，连通域分析后以 JPEG 子贴片贴回，正文矢量经 `show_pdf_page` 原样保留
6. 差分法统计各页水印去除率与文字保留率，输出图表

系统功能结构：交互层（文件选择弹窗/命令行/批量处理）→ 处理引擎（水印掩码/网格定位/文字图片保护）→ 分析模块（差分统计/图表输出）。

程序工作流程：选择 PDF → 逐页渲染（300 DPI）→ 亮灰水印掩码 + 文字/图片邻域保护 → 5×5 网格定位水印窗格 → 子贴片替换 → 输出去水印 PDF → 差分法统计去除率与文字保留率 → 图表。
